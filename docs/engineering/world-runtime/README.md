# World Runtime Engineering Documents

This directory contains engineering documents for implementing and evolving the world runtime.

These documents are separate from the project design documents under `docs/product/world-runtime/`.

## Documents

- [`repository-reuse-and-risk-controls.md`](repository-reuse-and-risk-controls.md): repository reuse audit, risk controls, package boundaries, and preparation order.

## Scope

Use this directory for engineering analysis, migration notes, repository audits, risk controls, technical preparation records, and implementation constraints.

Do not put core philosophy, product direction, conceptual models, or long-term architecture doctrine here unless they are quoted as context from the product design documents.
